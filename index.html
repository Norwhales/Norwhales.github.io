Dota 2 · анализ матча

Кто зарунил катку?

Вставь ID матча — сравним каждого игрока с тысячами других на том же герое и покажем, кто тащил, а кто кормил.

Подойдут ссылки с Dotabuff, OpenDota и STRATZ.

Friend ID есть в клиенте Dota (Друзья → Добавить друга). Профиль должен быть открыт.

Как считаем

Сравнение с героем

OpenDota знает, как обычно играют на каждом герое. Для каждого показателя берём перцентиль: 80% — лучше, чем у 80% игроков на этом герое.

Взвешенная оценка

Смерти весят больше всего (25%), дальше золото и урон по героям (по 15%), опыт, убийства, помощь, добивания (по 10%) и урон по строениям (5%).

Руин-метр 0–100

Чем выше, тем хуже игра относительно нормы. Ливнул из игры — сразу 95+. Это ориентир для споров в чате, а не приговор: цифры не видят варды, смоки и сейвы.

  • 0–34 Тащил
  • 35–54 Норм
  • 55–74 Подозрительно
  • 75–100 Руинер

Данные — OpenDota API. Проект не связан с Valve. Dota 2 — товарный знак Valve Corporation.
